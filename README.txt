QuickTools — Free Image Compressor
=================================

Files:
- index.html: Complete website in one file (HTML, CSS, JavaScript).

Test locally:
1. Double-click index.html to open it in a browser.
2. Choose a JPG, PNG, or WebP image.
3. Select output format and quality.
4. Click Compress image, then Download image.

Publish free with GitHub Pages:
1. Sign in at https://github.com/
2. Create a NEW PUBLIC repository named quicktools (or another name you prefer).
3. Click Add file > Create new file. Name it index.html.
4. Open the supplied index.html on your computer in Notepad, copy all its contents, and paste them into GitHub's editor.
5. Click Commit changes.
6. In the repository, open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose Branch: main and Folder: /(root), then click Save.
9. Wait a few minutes, then check the Pages URL shown on the Settings > Pages page. For a repository named quicktools, it is usually https://YOUR-USERNAME.github.io/quicktools/

Notes:
- This site processes images in the visitor's browser; images are not uploaded to a server by this code.
- PNG output can be larger than the original. JPEG output uses a white background for transparent images.
- GitHub Pages hosting is free for public repositories, but publishing means the source code is public.
- Advertising income is not guaranteed; traffic and ad-network approval are required.
